go-ruby-rack is a pure-Go (no cgo) reimplementation of the deterministic core of Ruby's Rack — the SPEC value types and the pure-compute utilities of Rack::Utils, Rack::Request, Rack::Response, Rack::MediaType and the header machinery — matching the MRI rack gem (Rack 3.x) byte-for-byte. It shapes a Rack environment, parses and builds query strings and cookies, escapes and unescapes URI/HTML, maps HTTP status codes, and produces the [status, headers, body] SPEC tuple — without any Ruby runtime. The HTTP server — the socket accept loop, TLS, Rack::Handler — is the host's job and stays out of scope; reading the body is one explicit Input seam. It is a standalone, reusable module — the Rack backend bound into go-embedded-ruby by rbgo, a sibling of go-ruby-regexp, go-ruby-erb and go-ruby-yaml — differential-tested against the rack gem, 100% coverage, CI green across 6 arches and 3 OSes.
